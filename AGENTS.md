# Repository guidance

This repository is a Nix flake for NixOS (`laptop-nixos`), nix-darwin (`macbook`), and Home Manager. Host imports live in `hosts/<name>/default.nix`; hardware-specific settings belong in `hosts/laptop-nixos/hardware.nix`. Shared and platform modules are organized under `modules/`, and local package assembly is in `packages/default.nix`.

## Checks

Run the same lint script CI uses:

```bash
bash scripts/lint.sh            # whole repository
bash scripts/lint.sh path...    # changed files
```

It checks Nix formatting, statix, deadnix, shellcheck, and actionlint. The formatter uses four-space indentation. For host evaluation, run `nix flake check`; CI lint alone does not evaluate both hosts. `hosts/laptop-nixos/hardware-configuration.nix` is generated by NixOS and excluded by the lint script.

## Conventions

- Keep related settings and imports together in the existing module layer. Host choices belong in the host module; keep shared Home Manager, NixOS, and Darwin configuration in their respective layers.
- Follow the surrounding file's formatting and module style. Combine repeated assignments under a single attribute set when the option naturally groups children.
- Keep a module's argument list to the values it uses.
- Use shared identity and path values from `vars` or Home Manager configuration instead of embedding host-specific paths in shared modules.
- Keep package definitions in `packages/`; install-only platform packages belong in that platform's package module. Service executables should come from declared packages.
- `dot` links files from `dotfiles/` into the working checkout, so edits to linked files take effect without a generation rebuild. The Gold Price services use packaged scripts from `dotfiles/local/bin`, so rebuild their package after changing those sources.
- The flake's `secrets` input defaults to `secrets/placeholder` for evaluation. Check the local secret setup before attempting a real machine rebuild.

Do not commit or push unless requested. A green lint run does not guarantee a host will boot.
